**The product defect behind check D, not fixed here because it needs a migration number outside this
session's block.** `v_gradebook_latest.counts_toward_grade` (047) reads `assignments.component_id`
alone and never the picker's link, in either direction. On prod today (read 2026-10-09):

* `GEO.103.lecture/exam-1`: linked to "First Exam" by the picker, flag **false**. It is an `item`
  column, so the Grades table shows it either way; nothing visible is wrong.
* `GEO.103.lecture/absences` and `GEO.103.recitation/attendance`: both marked "Not graded" by the
  picker (an excluded link), flag still **true**, because their assignments carry components 4 and
  5 from the V-1 data. `isItemRow` (`web/src/lib/queries.grades.ts`) lists an attendance column
  among the items when that flag is true, so the Grades table lists two columns as counting that
  he marked as not graded. The figure itself is right: the model view passes the link's `excluded`
  to the engine.
* The other way round is waiting to happen: an attendance column he places with the picker (ECN.304
  Attendance is on his list in ORCHESTRATOR §4) would count in the figure and still not be listed
  among the items.

The fix is one expression in one view: the flag is false under an excluded link, true under a
non-excluded link that carries a component, and otherwise what it is today. **Proved in a rolled-back
transaction on prod** (the live definition read with `pg_get_viewdef`, the expression replaced, the
view re-created, then rolled back; no request open): 73 rows before and after; exactly those three
rows change (exam-1 to true, the two attendance columns to false); the five views that read it
(`v_assignment_grade`, `v_course_grade`, `v_grade_model_items`, `v_grade_model_total`,
`v_assignment_attempts`) still answer with the same row counts; no grant moves. It changes what the
Grades table lists for GEO.103, so it is his to see before it merges. **Asked of Stack: a number for
it** (107 is free in Phase 16's own block, 105 to 109; this session's block has only 189, held for
Phase 23), and whether he wants the two attendance columns out of the item rows.
